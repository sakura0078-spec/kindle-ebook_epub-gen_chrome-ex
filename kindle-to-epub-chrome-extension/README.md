# Kindle to EPUB Chrome Extension

Web版Kindle Viewer（read.amazon.co.jp）から自動ページめくりで全ページをスキャンし、EPUB3ファイルとして出力するサイドパネル拡張機能です。

## インストール手順
1. ダウンロードしたZIPファイルを適当なフォルダに解凍します。
2. Google Chromeのアドレスバーに `chrome://extensions/` を入力して開きます。
3. 画面右上の **「デベロッパーモード」** をONにします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 解凍したフォルダを選択します。

## 使用方法
1. [Kindle Cloud Reader (read.amazon.co.jp)](https://read.amazon.co.jp/) で目的の書籍を開きます。
2. 画面の表示設定で **「単一ページ表示（1ページ表示）」** に設定します。
3. Chromeツールバーの拡張機能アイコン一覧から本拡張機能をクリックし、**「サイドパネル」** を開きます。
4. タイトルや出力設定（固定レイアウト／リフロー、画像形式、待機時間）を確認し、**「スキャン開始」** をクリックします。
5. 完了すると、自動的に `Downloads/KindleBooks/書籍タイトル.epub` に保存され、デスクトップ通知が表示されます。
